# ITR-TaxPilot Frontend

This directory contains the user-facing web application for ITR-TaxPilot.

## Features (Targeted for Phase 11 / Milestone 12)
- Form 16 Drag-and-Drop PDF Upload
- Multi-step parsing progress tracker
- Deterministic tax breakdown & regime comparison view
- ITR eligibility guidance
- Downloadable Tax Summary Report (PDF)
